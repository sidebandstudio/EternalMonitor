# Roadmap

This is what is coming to EternalMonitor, roughly in order. Each item ships when
it is ready, so there are no dates. [RELEASE_NOTES.md](RELEASE_NOTES.md) covers
what has already shipped.

## Next release: 0.3.4

Version 0.3.4 is in testing. It brings:

- **11 languages in both apps.** Pick one in a new first-run setup or in Settings.
- **The right graphics card on dual-graphics laptops.** When Windows runs
  EternalMonitor on the card that drives no screen, the PC switches it in one
  click.
- **A Troubleshooting section** in Settings for the graphics card, the encoder
  and smaller packets for VPNs.
- **A clear picture after a lost frame.** On Wi-Fi the iPad keeps the last clear
  picture while the next one arrives.
- **Steadier sessions** through slow disks, stuck graphics drivers and big screen
  changes over USB.

## Coming next

- **Signed Windows installer.** Code signing is built into the release pipeline
  and turns on once the signing account is set up.
- **iPad app on the App Store.** The iPad app installs through TestFlight today.
  An App Store release is planned.
- **Community compatibility list.** Measured results from the PCs and iPads
  people use: which setups work, how smooth they feel and the latency the apps
  report, published on the [compatibility page](https://eternalmonitor.dev/compatibility.html).
  Send yours with the [compatibility report](https://github.com/sidebandstudio/EternalMonitor/issues/new?template=compatibility.yml).
- **Mac.** Use your iPad or iPhone Duo as a second screen for your Mac.
- **iPhone Duo.** Use your iPhone Duo as a second screen, with a separate app,
  EternalMonitor Duo, and its own TestFlight.
