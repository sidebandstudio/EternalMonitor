# EternalMonitor translation glossary

Shared by the Windows app, the iPad app, the installer and the website, so the
same thing has the same name everywhere. The iPad tells people which button to
press on the PC, so these must match exactly across apps.

Translations are AI drafts for the 0.3.4 beta. Native speakers review them
before the stable release.

## Never translated

EternalMonitor, iPad, iPadOS, Windows, Apple Pencil, Apple Devices (the app),
Wi-Fi, USB, QR, NVIDIA, AMD, Intel, H.264, HEVC, fps, Mbps, TestFlight.
