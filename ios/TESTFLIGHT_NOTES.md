# EternalMonitor 0.3.6: What to Test

Windows and iPad versions listed on the download page work together.
Each 0.3.6 app works with the other app on 0.3.5, 0.3.4 and 0.3.3.

### Second screen

- Portrait for the second screen: Settings > Display > Orientation makes
  it a tall screen, for a chat or a long page with the iPad held upright.
  Mirroring a screen turned to Portrait in Windows now shows a picture
  instead of none.

### Diagnostics

- Automatic diagnostics go to EternalMonitor's new support address.
  Update both apps so we keep receiving reports when something goes wrong.
- Routine log lines stay on your device. The apps send warnings, errors,
  crash reports and a short summary of each session and connection
  attempt. The privacy policy lists what is sent.

### Known issues

- If Windows has set the virtual display to **PC screen only**, Second
  screen shows the PC's own screen. Press Win+P and choose **Extend** once.
