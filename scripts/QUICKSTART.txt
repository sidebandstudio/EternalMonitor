EternalMonitor v0.3.0 candidate - Quick Start
============================================
Use your iPad as a second display for a Windows PC, over WiFi or USB.
You need matching Windows and iPad builds. The candidate is still being
verified; use the installer and TestFlight invite supplied together.
The latest older public installer does not include every feature below.

What you need
-------------
- Windows 10/11, a supported NVIDIA/AMD/Intel GPU, and the host installer.
- iPadOS 17 or later and the EternalMonitor app through TestFlight or Xcode.
- A trusted local network for WiFi. Ethernet for the PC usually helps.
- For USB: a data cable, Apple Devices or desktop iTunes on Windows, and
  acceptance of the iPad's Trust This Computer prompt.

1. Install the matching build
----------------------------
Download EternalMonitor-Setup.exe from the project's release page and
check its published SHA-256. The unsigned installer may show SmartScreen;
use More info > Run anyway only for the build you intended to install.
Approve the installer UAC prompt. It installs the host, virtual display
and its tasks, plus TCP/UDP firewall rules. Start EternalMonitor.

Install Apple's TestFlight app, then open the supplied invite link for the
matching EternalMonitor build. TestFlight invite: ask Ali if no link was
supplied. An unsigned developer archive is not a TestFlight install.

2. Connect and pair over WiFi
----------------------------
Keep the PC and iPad on the same local network, outside a guest network.
In the iPad app, Scan for the PC or enter the address shown by the host
(default port 9876). Enter the six-digit pairing code shown on the PC.
Scanning the host QR instead carries its pairing token and skips code entry.
The app remembers the host. On the PC, Settings > Forget all iPads resets pairing.
Pairing does not encrypt video, audio or input; use a network you trust.

3. Connect by USB
----------------
Keep the iPad app open, plug in a data cable and accept Trust This Computer.
The app should show USB. A cable can take over an existing WiFi stream;
unplugging falls back to WiFi if that host remains reachable.

If the USB card asks for Apple's device service, install Apple Devices or
desktop iTunes and reconnect the cable. The service must expose usbmuxd at
127.0.0.1:27015. Physical cable/service verification is still pending in
this candidate; include the card's exact message in a failure report.

4. Choose mirror or extended display
-----------------------------------
Connect first. On the PC's Stream page, set Display to Extended display
(iPad), then click Restart now. Drag windows into the new Windows display.
To mirror again, choose Main display (mirror) and restart.
The virtual display should disappear on disconnect and host exit. If it
cannot start, collect the host log and rerun the matching installer.

5. Audio, keyboard and pointer
-----------------------------
Enable Stream PC audio on the host and Play PC audio on the iPad. The
speaker indicator shows playback; muting on the iPad leaves video running.
Audio follows the Windows default output device.

With Control PC with touch enabled:
- Tap clicks, drag moves with the button down, two fingers scroll, and a
  hold gives right-click. Pencil position also controls the mouse.
- Three-finger tap reveals the controls. Keyboard opens the on-screen
  keyboard and Esc/Tab/modifier/arrow accessory keys.
- Hardware keyboards relay text and shortcuts. The default maps Command
  to Ctrl; choose Win in Settings if needed. iPadOS retains Globe, Command-H,
  Command-Tab and Command-Space.
- Supported trackpads/mice relay secondary/middle click, scroll and hover.
- For view-only, turn Control PC with touch off and reconnect.

6. Quality and frame rate
-------------------------
Start at 60 fps and H.264. HEVC is optional in host Settings. The effective
rate is the lower host/iPad preference; 120 Hz needs a suitable iPad,
virtual display mode and enough encoder/network capacity.

If motion stutters, inspect loss/repairs/jitter and capture/encode/decode
FPS. Try a stronger WiFi signal, 5 GHz or Ethernet on the PC. A software
fallback banner means the hardware encoder did not open; collect its error,
update the GPU driver and restart. Keep the default YUV420 input unless
explicitly testing the BGRA option.

Connection troubleshooting
--------------------------
- Try the host's LAN IP instead of discovery; keep its window open.
- Confirm both builds came from the same candidate.
- The v0.3 installer configures Windows Firewall. If a security product or
  an older installation blocks it, allow the host in Windows Security >
  Firewall & network protection > Allow an app through firewall.
- Check the pairing code or regenerate the token and pair again.
- On USB, report the cable, trust state and USB card text.

What to report
--------------
Record both versions, iPad model/iPadOS, Windows GPU and active codec,
WiFi/USB, capture target, and what failed. Use Copy logs on the host's
Performance page. Session logs also live at:
%APPDATA%\EternalMonitor\logs\eternal-host-session.log
Previous sessions are .1 and .2. Redact pairing tokens and QR codes before
posting logs publicly. HARDWARE_VERIFICATION.md lists the remaining iPad
checks and expected results.
