Company logos for the "Built by engineers from" strip (index.html, download.html).
Each file is the company's own artwork, unredrawn: metadata removed, the viewBox
cropped to the drawing. The page turns every logo one colour with a CSS filter,
so the original colours stay in the files. Trademarks of their owners.
