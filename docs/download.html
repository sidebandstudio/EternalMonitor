          Both apps send diagnostics while they run, including PC and iPad names, audio device names and network addresses. Never your screen, audio or pairing codes. Kept up to 30 days, sometimes less, and up to 7 more days in backups. Turn it off in Settings. Details.
        
    
      
    
    
    

    
    
      
    
        
    
          Build from source
          
    
            
    Requirements
    
            
      
              
    • Windows 10 version 1809 or later, or Windows 11
      • 
              
    • Rust 1.98.0 with the MSVC toolchain (pinned by rust-toolchain.toml), and LLVM/libclang
      • 
              
    • FFmpeg 7.1 shared SDK (set FFMPEG_DIR)
      • 
              
    • A GPU with a hardware encoder (NVIDIA, AMD or Intel), or the software fallback
      • 
            
    
            
    Windows app
    
            
    git clone https://github.com/sidebandstudio/EternalMonitor
cd EternalMonitor
$env:FFMPEG_DIR = "C:\ffmpeg"   # your FFmpeg 7.1 shared SDK
cargo build --release -p eternal-host
    
            
    iPad app
    
            
    cd ios
xcodegen generate
# Open EternalMonitor.xcodeproj in Xcode and build for your iPad
    
            
    The README has the macOS development loop and the test suites.
