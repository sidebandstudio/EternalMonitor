Join the TestFlight beta
  1. Install TestFlight from the App Store on your iPad.
  2. Open the invite on the iPad, then tap Accept and Install.
  3. Open EternalMonitor and pair it with your PC.

Build from source

Requirements

  • Rust stable with the MSVC toolchain
  • FFmpeg 7.1 shared SDK (set FFMPEG_DIR)
  • A GPU with a hardware encoder (NVIDIA, AMD or Intel), or the software fallback

Windows app

git clone https://github.com/sidebandstudio/EternalMonitor
cd EternalMonitor
$env:FFMPEG_DIR = "C:\ffmpeg"   # your FFmpeg 7.1 shared SDK
cargo build --release -p eternal-host

iPad app

cd ios
xcodegen generate
# Open EternalMonitor.xcodeproj in Xcode and build for your iPad
