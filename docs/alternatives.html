    Ways to use an iPad as a display for a Windows PC

    Several apps turn an iPad into a screen for a Windows PC. This page puts what each maker says on its own pages side by side. Where a maker doesn't say, it reads "not stated". We make EternalMonitor, so it is listed first. Checked October 2026.

    First, Sidecar is for a Mac

    Apple's Sidecar extends or mirrors a Mac onto an iPad, over Wi-Fi or a cable. It needs a Mac with macOS Catalina or later, so it does not work with a Windows PC. Windows has no built-in way to use an iPad as a screen either, so each option below runs an app on the PC. On the iPad, most use their own app; Deskreen uses the web browser. Source: Apple Support.

    Who EternalMonitor suits

    Anyone with a Windows PC and an iPad who wants a second screen or a drawing tablet without paying for one.

    • Free and open source. MIT license, no account, and code you can read.
    • Your graphics card does the work. NVIDIA NVENC, AMD AMF or Intel Quick Sync encode H.264 or HEVC at 30, 60, 90 or 120 fps, with 120 on iPads with ProMotion.
    • Wi-Fi or USB. A cable takes over a running Wi-Fi session and charges the iPad. Unplug it and the stream goes back to Wi-Fi.
    • Apple Pencil as a real pen. Windows receives pressure and tilt as Windows Ink, and Drawing mode ignores your palm on the canvas.
    • Loss repair for real Wi-Fi. The iPad asks again for a missing packet right away, so one dropped packet rarely costs a frame.
    • PC audio. Sound plays on the iPad, and you can mute it without stopping the video.
    • Updates in one click. On Windows, Update now checks the download and installs it.
